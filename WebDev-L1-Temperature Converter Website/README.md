# 🌡️ Temperature Converter

A simple and responsive Temperature Converter web application built using HTML5, CSS3, and JavaScript. This application allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin with input validation and user-friendly error handling.

## 📌 Project Overview

This project provides an easy-to-use interface for converting temperatures between different units while handling invalid inputs and preventing temperatures below absolute zero.

## ✨ Features

- Convert Celsius, Fahrenheit, and Kelvin
- Input validation for numeric values
- Error messages for invalid input
- Absolute zero validation
- Responsive user interface
- Clean and modern design
- Easy-to-use controls

## 🛠️ Technologies Used

## 🌡️ Conversion Formula

### Celsius to Fahrenheit

```
°F = (°C × 9/5) + 32
```

### Fahrenheit to Celsius

```
°C = (°F − 32) × 5/9
```

### Celsius to Kelvin

```
K = °C + 273.15
```

### Kelvin to Celsius

```
°C = K − 273.15
```
