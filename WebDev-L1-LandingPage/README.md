# 👕 VELORA - Clothing Brand Landing Page

VELORA is a modern and responsive landing page created for a fictional premium clothing brand. The project showcases a clean user interface, responsive layout, and attractive design using only HTML5 and CSS3.

## 📌 Project Overview

The landing page is designed to introduce the VELORA clothing brand, highlight featured collections, and encourage users to explore the products through a visually appealing interface.

## ✨ Features

- Responsive navigation bar
- Hero section with headline and call-to-action button
- Featured clothing collection
- Why Choose Us section
- About the brand section
- Customer reviews
- Call-to-action section
- Footer with social media links
- Fully responsive design
- Clean and modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome Icons
